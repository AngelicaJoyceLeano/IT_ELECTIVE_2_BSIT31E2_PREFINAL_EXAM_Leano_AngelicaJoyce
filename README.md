## Project Description

This project is an ASP.NET Core MVC application created for the
IT Elective 2 Web System and Technologies Pre-Finals Examination.

The application displays the examination questions and allows the
student to view and select answers.

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Restore the NuGet packages.
4. Run the project.
5. Open the browser.
6. Navigate to the Exam page.
